# raw-sources/photos/

Kho ảnh đời sống gốc. Lưu theo `YYYY-MM/<timestamp>-<slug>.jpg`.

## Quy tắc bất biến (immutable)

- AI chỉ đọc. Không bao giờ sửa, xóa, đổi tên, nén lại file gốc.
- Bản phân tích của mỗi ảnh nằm ở `wiki/photos/<slug>.md`, liên kết ngược về file gốc bằng đường dẫn tương đối.
- Ảnh là một phần của private repo, không ignore trong `.gitignore`.
- Không đưa ảnh chứa CCCD, giấy tờ tùy thân vào đây. CCCD là dữ liệu nhạy cảm, lưu riêng theo quy tắc ở Phase 07 của dự án quản lý trọ.
