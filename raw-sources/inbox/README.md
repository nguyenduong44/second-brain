# raw-sources/inbox/

Ghi chú nhanh, link bài viết, transcript — dữ liệu thô, chưa biên soạn.

## Quy tắc bất biến (immutable)

- AI chỉ đọc. Không bao giờ sửa, xóa, ghi đè file trong `raw-sources/`.
- Ghi chú thô mới → tạo file mới, tên `YYYY-MM-DD-<ten-ngan>.md`. Không sửa file cũ để "cập nhật" nó.
- Khi một ghi chú thô đã được biên soạn thành wiki, ghi lại trong `wiki/log.md` là nó đã được xử lý, nhưng file gốc vẫn giữ nguyên.
